# Solução proposta

O Agende Bem reduz o trabalho manual após uma desistência sem automatizar indevidamente uma decisão da recepção. O sistema encontra a janela liberada, avalia toda a lista de espera e explica cada sugestão ou rejeição.

O algoritmo é determinístico: compatibilidade profissional, duração, disponibilidade e ausência de conflito são requisitos; tempo de espera, sobra de minutos e ordem de cadastro definem a prioridade. A confirmação recalcula os critérios dentro da transação para impedir encaixes obsoletos ou duplicados.

Consulte [../BUSINESS_RULES.md](../BUSINESS_RULES.md) para os critérios completos.
