# Saúde — Desafio 2: Agenda inteligente para uma clínica

| Requisito do desafio | Implementação no Agende Bem |
| --- | --- |
| Carregar agenda CSV | Importar / Exportar valida CSV e grava a agenda do dia |
| Cadastrar lista de espera | Tela Lista de espera registra duração, janela e profissionais |
| Sugerir encaixes | `scheduler.py` avalia e ordena candidatos |
| Cancelamento | Agenda abre confirmação e cria janela livre |
| Confirmar substituição | Central de encaixes exige seleção e confirmação manual |
| Salvar agenda atualizada | Serviço transacional grava encaixe e atualiza lista/auditoria |

O limite original de uma clínica, um dia e três profissionais é preservado. Dashboard, Auth/RBAC, arquivos e modelos são evoluções V3, apresentadas separadamente.
